* From web applications to AI and telecom
:PROPERTIES:
:CUSTOM_ID: from-web-applications-to-ai-and-telecom
:END:

The career began with web applications: PHP, Drupal, Zen Cart, and client-
facing products. It grew through Ruby on Rails systems, analytics platforms,
ETL pipelines, logistics software, and developer tools.

Over time, the work moved into systems where software has to coordinate more
than a browser request. That includes real-time tracking, financial
origination, healthcare logistics, GPU-backed image generation, and telecom
infrastructure.

Telecom and voice systems still use a great deal of web technology: APIs,
databases, queues, distributed services, cloud infrastructure, and web
frontends. The difference is that the system must also handle live audio,
signalling, provider integrations, strict latency budgets, and failures while
people are actively using it.

That path led naturally to AI systems. The central engineering questions stay
the same: where state lives, how services fail, how data moves, and how to keep
complex systems understandable.

* About Self dot send
:PROPERTIES:
:CUSTOM_ID: about-self-dot-send
:END:

Self dot send is Pankaj's engineering notebook. It covers the ideas and
implementation details behind programming languages, web and distributed
systems, telecom and voice infrastructure, developer tools, and applied AI.

Most posts begin with a problem encountered while building software. The goal
is to explain the model, show the implementation, and record the trade-offs
that are easy to lose once the code works.

Posts are written in Org files and published through an editor-first workflow
using [[https://github.com/metacritical/AOG][AOG]], a customized Emacs Org-mode static publishing system.
